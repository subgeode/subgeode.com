        Filming
        I used an iPhone to film myself performing a pole climb on both sides. I cropped the footage and imported it into TouchDesigner.


        TouchDesigner
        I sped up the video and set a loop crossfade. I connected an Info CHOP to find the total number of frames which I then set the timeline to match. I cued the file on the first frame of the timeline.

        I connected two Level TOPs to get the black level, brightness, gamma, and contrast where I wanted.

        I connected an HSV Adjust TOP to modify the hue offset. I used a Timeline CHOP and Math CHOP to create a reference number that perfectly loops the hue.

        I added a Feedback TOP, Level TOP, and Composite TOP to create a smoky trail effect.

        I ended with a Movie File Out TOP to export as a Motion JPEG at 60 FPS.


        FFMPEG
        To reduce file size while retaining as much quality as possible I converted the exported movie into .mp4 using H.264.
